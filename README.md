# Agras Field Tracker (Android)
Capacitor wrapper around AgrasFieldTracker_4.html, fully offline (React/Tailwind/fonts bundled).
- Edit `app/src.html`, then `cd app && node build.js && npx cap sync android`.
- APK: push to GitHub -> Actions -> "Build Android APK" -> download artifact `app-debug.apk`.
- Or open `app/android` in Android Studio.
