# ข้อเสนอ: พ่นต่อจากจุดที่น้ำหมดถัง (resume point)

สถานะ: **ข้อเสนอ ยังไม่ได้สร้าง** — เขียน 2026-10-01 จาก session คลาวด์
ที่ยังเข้าถึง log จากมือถือไม่ได้ เจ้าของขอให้ดู log การพ่นจริงก่อนออกแบบ
(ดู "ขั้นตอนต่อไป")

## ตัดสินใจแล้ว (เจ้าของตอบ 2026-10-01) — ใช้แทนคำตอบแนะนำด้านล่างเมื่อขัดกัน

1. เส้นนำทาง: **เส้นประตรง** จากตัวเราไปจุดหมาย
2. เริ่มพ่นไกลเกิน 8 m: **เตือนบรรทัดเดียว ไม่บล็อก**
3. น้ำหมดกลางเลน: **ไม่กลับไปต่อเลนเดิม** ให้พ่น **แถวใหม่ที่ใกล้สถานีเติมน้ำ**
   - จุดหมายของเส้นประและชิป `ไปแถวต่อไป · N m` คือต้นแถวที่ยังไม่ได้พ่นและใกล้สถานีที่สุด
   - `lastStop` ยังเก็บไว้เพื่อรู้ว่าเลนที่ค้างเหลือส่วนที่ยังไม่พ่น
4. ส่วนที่เหลือของเลนที่ค้าง: **ทำเป็นรอยขาดสีแดง** (ระบบ `missed`) หายเองเมื่อเดินกลับมาพ่นเก็บ
5. ปิดจอระหว่างเดินกลับ: **ไม่สั่นเตือน**

สร้างแล้วในโค้ด (2026-10-01) ทดสอบใน SIM และชุดเทสต์ GPS ยังไม่ได้ลงมือถือ ดู HANDOFF.md หัวข้อ "Next lane after a refill"

## ที่เห็นจาก log จริง (backup `ls_field_l.json`, 30 ก.ย. เย็น และ 1 ต.ค. เช้า)

- ถังหนึ่งคือเลนยาวเลนเดียว 110 ถึง 160 m ใช้เวลาพ่น ~4 นาที เดินทางเดียวจากฝั่งสถานีไปปลายเลน
- น้ำหมดที่ปลายเลน (ห่างสถานี ~225 m) เดินกลับเปล่า ~4.5 นาที อยู่ที่สถานี ~11 นาที เดินกลับ ~3 นาที
- ถังถัดไปเริ่มที่ต้นเลนข้างเลนเดิม ห่างสถานี ~70 m และกด REFILLED ตรงจุดนั้น ไม่ใช่ที่สถานี
- จอดับตลอดทางไปสถานี เปิดตอนออกจากสถานี
- ถัง 2 เช้า 1 ต.ค.: ปุ่ม TANK EMPTY ไม่ตอบ ~4 นาที (เจ้าของจำได้ ไม่แน่ใจ) log เห็นแอปทำงานปกติ ยังไม่พบสาเหตุ
- ตัวอย่างเล็ก: 2 วัน 4 ถัง


## ของเดิม (`app/src.html`)

- `tankEmpty()` ปิดการบันทึก แล้วชี้ไปสถานี (`opMode = 'toStation'`)
- `resumeSprayingNow()` เปิดบันทึกอีกครั้ง **ตรงที่ผู้ใช้ยืนอยู่** แอปไม่รู้ว่าต้องกลับไปตรงไหน
- มี `sim.lastSprayPos` (จุดพ่นล่าสุด) บันทึกลงแปลงเป็น `entry.lastStop`
  และ `drawMap` วาดเป็นวงแหวนขาว/จุดอำพันบนหน้าแรกอยู่แล้ว (`opts.lastStop`)
- ระบบ breakpoint เดิมถูกถอดตามแผนผังของเจ้าของ (กดสองครั้ง ไม่ใช้ GPS ตัดสิน)
  เหลือแค่ `sim.breakpoint = null` ค้างอยู่

## แบบที่เสนอ: "จุดต่อ" ที่ไม่ผูกกับ GPS ว่าถึงหรือยัง

เก็บแนวคิดกดสองครั้งไว้ เพิ่มแค่การนำทางกลับ

1. **กด TANK EMPTY** — บันทึก `resumePoint = {x, y, heading, laneId}` จากตำแหน่งพ่นล่าสุด
   เก็บลงไฟล์ session และลงแปลง (ใช้ `entry.lastStop` ตัวเดิม) ให้รอดการปิดแอป
2. **ระหว่างเดินกลับ** — วาดหมุดจุดต่อ (สไตล์เดียวกับ lastStop) + เส้นประขาวจากตัวเรา
   ไปจุดต่อ + ชิป `กลับไปต่อ · N m` เมื่อออกจากสถานีเกิน 15 m
   (ตรงกับตอนที่ pill "ไปสถานี" หายพอดี, `reachedStationRef`)
   ถ้า ROUTE เปิดอยู่ ให้เน้นช่วงเลนที่เหลือจากจุดนี้
3. **กด REFILLED · START SPRAYING** — ไม่บังคับให้ถึงจุดต่อ ถ้าห่างเกิน 8 m เตือนบรรทัดเดียว
   ("ยังห่างจุดต่อ N m") ไม่ล็อกปุ่ม เริ่มบันทึกทันที การเดินจากจุดต่อถึงจุดที่กดเริ่ม
   ไม่นับเป็นการพ่น
4. **กันช่องว่างตรงรอยต่อ** — ถ้าเริ่มพ่นห่างจุดต่อเกิน 3 m ให้ทำเครื่องหมายช่วงระหว่าง
   จุดต่อกับจุดเริ่มเป็นรอยขาดสีแดงด้วยระบบ `missed` ที่มีอยู่ ถ้าเดินกลับมาพ่นเก็บภายหลัง
   รอยขาดหายเอง

## คำถามที่ต้องให้เจ้าของเลือก (ค่าแนะนำตัวหนา)

1. เส้นนำทางกลับ: **ตรงไปจุดต่อ** หรือเดินตามขอบแปลง
2. เริ่มพ่นไกลจากจุดต่อ: **เตือนอย่างเดียว** หรือบล็อกจนกว่าจะถึงรัศมี
3. น้ำหมดกลางเลน: **ต่อเลนเดิมทิศเดิม** หรือเลือกเลนเอง
4. ปิดจอระหว่างเดินกลับ: สั่นเมื่อถึงจุดต่อภายใน 5 m หรือไม่

## ที่ต้องแก้และต้องเทสต์

- `src.html`: `tankEmpty`, `resumeSprayingNow`, ตัวแสดงชิป, `drawMap` (ใช้ `opts.lastStop` ซ้ำได้)
- เพิ่ม `resumePoint` ใน session snapshot โดยรองรับ snapshot เก่าที่ไม่มีฟิลด์นี้
- เทสต์ใหม่ใน `app/test/run.js` เช่น `resumePoint`: จุดต่อรอดการรีโหลด,
  เตือนเมื่อเริ่มห่างจุดต่อ, รอยขาดตรงรอยต่อ
- ทุกการเขียน field library ต้องผ่าน `updateLibrary()` (ดู HANDOFF)
- ก่อนสร้าง ต้องส่งภาพหน้าจอขนาดมือถือให้เจ้าของดูตามธรรมเนียมของโปรเจกต์

## ขั้นตอนต่อไป: ดู log การพ่นจริงก่อนปรับแบบ

Session คลาวด์ดึงจากมือถือไม่ได้ (ไม่มี adb) ให้ session local ที่เสียบสายอยู่ดึง
test log และประวัติภารกิจของแอปทดสอบ (วิธีใน HANDOFF หัวข้อ "Driving the app on
the phone", หรือ Settings → Test log → SHARE) โดยเฉพาะวันที่ 22–23 ก.ย.
(แปลงถั่ว 2 มีการเติมน้ำจริงหลายถัง) แล้ววัด:

1. ตอนกด TANK EMPTY อยู่ตรงไหนของเลน (กลางหรือท้ายเลน)
2. เวลาและระยะเดินไปสถานีและกลับ
3. ตอนกด REFILLED อยู่ห่างจากจุดที่น้ำหมดกี่เมตร และไปเริ่มพ่นที่ไหน
4. มีรอยขาดหรือพ่นซ้ำตรงรอยต่อหรือไม่
5. ปิดจอระหว่างเดินกลับนานเท่าไร

แล้วปรับค่าตัวเลข (8 m, 3 m, 5 m, 15 m) และคำตอบข้อ 1–4 ให้ตรงกับวิธีพ่นจริง
